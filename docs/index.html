TRY THE ASSET STUDIO

1

Clone the repo

Requires a local Content/Extracted tree (produced by the extraction tooling from a retail APB install — not distributed here).

2

Start the server

# Python 3.11+
cd tools/content-studio/server
python -m venv .venv && .venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m uvicorn main:app --port 8777
3

Start the web app

# Node 18+
cd ../web
npm install && npm run dev # http://localhost:5173
4

Build the game (UE 5.8)

powershell -File tests/build_and_run.ps1
D:\UE58\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe APBReloaded.uproject -game -windowed -log
